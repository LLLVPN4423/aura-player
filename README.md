# Aura — Premium Minimalist Hi‑Fi

Trình nghe nhạc phong cách **Premium Minimalist Hi‑Fi** (cảm hứng dCS Mosaic, Devialet, Volumio Nova, Auris): artwork lớn, chữ sạch, kỹ thuật nằm trong Studio — dễ dùng nhưng đủ chức năng audiophile.

## Thiết kế

- Listening-first: cover + title + transport là tâm điểm
- Palette charcoal ấm + champagne, typography Manrope
- Queue / Sound / Lab tách lớp — không làm ồn hero
- Tối ưu máy yếu: 3 mức hiệu năng

## Nghe nhạc cao cấp

| Tính năng | Mô tả |
|-----------|--------|
| Crossfade | 0–8s chuyển bài mượt (dual audio path) |
| Loudness normalize | Cân mức to nhỏ giữa các bài |
| Headphone crossfeed | Giảm mệt stereo khi nghe tai nghe |
| Balance | Cân trái/phải |
| Soft limiter | Chống clip khi boost EQ/norm |
| EQ 10 band + presets | Flat, Bass, Vocal, Acoustic, Night, Bright |
| Quality badge | Lossy / Lossless / Hi‑Res + sample rate |
| Sleep timer | 15/30/45/60 phút, fade out |
| Favorites | Đánh dấu bài yêu thích |
| Media Session | Điều khiển từ lock screen |
| Lab | Peak, RMS, BPM, DR, waveform |

## Chạy

